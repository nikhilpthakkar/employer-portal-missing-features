# Employer Portal: flex endorsement UX demo

Interactive prototypes of three approaches to adding, updating and removing employees across multiple flexible plans, and to viewing an employee who is on several plans:

1. **Simplest fix**: same screens, readable plan picker, one field per add-on group
2. **Ideal UX**: coverage builder, life events, before → after review
3. **Agentic**: describe a change and review a drafted endorsement

**Open the demo:** https://nikhilpthakkar.github.io/employer-portal-missing-features/

Everything runs in the browser with dummy data. There is no backend, no login and no real employee data. Submissions are saved only in your own browser.

This repository contains only the built static site.
